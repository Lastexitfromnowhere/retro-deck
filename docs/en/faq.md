# FAQ

[← README](../../README.md) · [Français](../fr/faq.md)

**Is it available?** Yes, in early access: version 0.1 for Windows is on sale as a one-time purchase.

**How much does it cost?** See the offers on the [campaign page](https://retrodeck.lastparadox.dev/campagne#paliers). One-time payment, no subscription.

**Is there AI in it?** This version has no AI feature and sends no data to any AI service. An edition with local, on-device AI is being considered.

**Does "no cloud" mean never any network?** The core is fully local and no account is required. Any optional component that used the network would be clearly labelled.

**Is the app made for ADHD?** It is designed to be calm and limited: few choices, no notifications. It is not a medical device and promises no therapeutic effect.

**What if the project stops?** The app works without a server or mandatory online check, and your notes are `.md` files that any editor opens.

**Can I see the code?** The application is proprietary. This repository contains the documentation, the design charter and the website source.

**macOS / Linux?** Considered, with no commitment or date.
