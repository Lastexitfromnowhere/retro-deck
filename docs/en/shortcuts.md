# Shortcuts

[← README](../../README.md) · [Français](../fr/shortcuts.md)

| Key | Action |
|---|---|
| `Ctrl+O` | Save |
| `Ctrl+X` | Close the note (or cut when text is selected) |
| `Ctrl+K` / `Ctrl+U` | Cut the line / paste the cut line |
| `Ctrl+W` | Search (Enter: next) |
| `Ctrl+L` | Go to line number |
| `Ctrl+R` | Insert a file at the cursor |
| `Ctrl+G` | Editor help |
| `Ctrl+E` | Toggle reading / writing |
| `Ctrl+J` | Create a card from the selection |
| `Ctrl+N` | New empty note |
| `Ctrl+B` / `Ctrl+Shift+B` | Fold the menu / open the note list |
| `Alt+arrows` | Directional pad from an input field |
| `Ctrl+Space` | Park a thought |
| `Ctrl+Shift+T` / `Ctrl+Shift+S` | Concentration / session |
| Hold `Esc` 2 s | Leave concentration, stop the session, close the project |

`Ctrl+C` and `Ctrl+V` remain the system copy and paste.
