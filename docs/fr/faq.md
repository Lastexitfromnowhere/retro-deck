# FAQ

[← README](../../README.fr.md) · [English](../en/faq.md)

**C'est disponible ?** Oui, en accès anticipé : la version 0.1 pour Windows est en vente en achat unique.

**Combien ça coûte ?** Voir les offres sur la [page campagne](https://retrodeck.lastparadox.dev/campagne#paliers). Paiement unique, sans abonnement.

**Y a-t-il de l'IA dedans ?** Non. Aucune fonction d'IA, aucune donnée envoyée à un service d'IA.

**« No cloud », ça veut dire jamais de réseau ?** Le cœur est entièrement local et aucun compte n'est requis. Tout composant optionnel qui utiliserait le réseau serait clairement indiqué.

**L'application est-elle faite pour le TDAH ?** Elle est pensée pour être calme et limitée : peu de choix, pas de notifications. Ce n'est pas un dispositif médical et elle ne promet aucun effet thérapeutique.

**Et si le projet s'arrête ?** L'application fonctionne sans serveur ni vérification en ligne obligatoire, et tes notes sont des fichiers `.md` que n'importe quel éditeur ouvre.

**Je peux voir le code ?** L'application est propriétaire. Ce dépôt contient la documentation, la charte graphique et la source du site.

**macOS / Linux ?** Envisagés, sans engagement ni date.
