# Raccourcis

[← README](../../README.fr.md) · [English](../en/shortcuts.md)

| Touche | Action |
|---|---|
| `Ctrl+O` | Enregistrer |
| `Ctrl+X` | Fermer la note (ou couper si du texte est sélectionné) |
| `Ctrl+K` / `Ctrl+U` | Couper la ligne / coller la ligne coupée |
| `Ctrl+W` | Chercher (Entrée : suivant) |
| `Ctrl+L` | Aller à la ligne n° |
| `Ctrl+R` | Insérer un fichier à la position du curseur |
| `Ctrl+G` | Aide de l'éditeur |
| `Ctrl+E` | Basculer lecture / écriture |
| `Ctrl+J` | Créer une fiche depuis la sélection |
| `Ctrl+N` | Nouvelle note vide |
| `Ctrl+B` / `Ctrl+Maj+B` | Replier le menu / ouvrir la liste des notes |
| `Alt+flèches` | Croix directionnelle depuis un champ de saisie |

`Ctrl+C` et `Ctrl+V` restent le copier-coller du système.
